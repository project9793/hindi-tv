1 GitHub connection

Fine-grained token banao jisme is repo ke liye Contents: Read and write ho.

Token kaise banayein (4 steps)
  1. github.com/settings/personal-access-tokens/new kholo → Generate new token
  2. Repository access → Only select repositories → project9793/hindi-tv chuno
  3. Permissions → Repository permissions → Contents = Read and write
  4. Generate → token copy karo, neeche paste karo

Token sirf aapke browser (localStorage) me rehta hai aur sirf GitHub API ko bheja jata hai. Shared computer pe use na karo.
