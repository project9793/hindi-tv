Playlist Manager

Add a channel to your GitHub playlist

Naam, logo aur stream URL bharo — ye page seedha aapke GitHub repo ki .m3u file me channel add kar dega. Kuch install karne ki zaroorat nahi.

1 GitHub connection

Ek fine-grained personal access token banao jisme sirf is repo ke liye Contents: Read and write permission ho.

Token sirf aapke browser me (localStorage) save hota hai aur kisi aur jagah nahi jata — sirf GitHub API ko bheja jata hai. Public/shared computer pe use na karo.

2 New channel

Pehle connection save karo, phir playlist list load hogi.
